You may not make people think your version is the official TradeX.

The main mark is the **TradeX X logo**: a red thunder bear arrow crossing a straight chrome-green bull arrow, on black and
chrome silver, as used in the app icons (`hub/web/brand/`) and on the chart. The logo, the app icons and the name
"TradeX"™ as used for this software ("TradeX by Saifullah Shafin") are trademarks of Saifullah Shafin. They are not
registered yet, which does not change these rules.

**Not the same project as TradeX Chart.** This TradeX is not affiliated with, endorsed by or connected to
[TradeX Chart](https://github.com/tradex-app/TradeX-chart) (the `tradex-chart` JavaScript library by tradex-app)
or to any other product with a similar name. Nothing in this policy makes any claim against their name or project.

## Official TradeX
Only these are official:
- the code at https://github.com/saifullahshafin/open-source-tradingview and its releases
- any other site or account that the README above lists as official

## You may, without asking
- Run, study, change and share the code under the AGPL-3.0.
- Say your project is "based on TradeX", "a fork of TradeX" or "compatible with TradeX", in plain text.
- Give the attribution line that [NOTICE](NOTICE) requires ("Based on TradeX by Saifullah Shafin"). That line is
  required, and this policy never forbids it.
- Share the unchanged official releases under the TradeX name, with the logo, as long as they really are unchanged.
- Write about TradeX: reviews, tutorials, videos, news, comparisons.

## You need written permission to
- Publish a modified version, a hosted service, an app-store listing or any product under the name TradeX or a
  name easily confused with it in a way that suggests it comes from this project (for example "TradeX Pro" or
  "TradeX Web").
- Use the X logo or the TradeX icons, or a logo that looks like them, on a modified version or on anything else
  that is not official TradeX.
- Use TradeX in a domain name, company name or social media handle.
- Suggest that Saifullah Shafin or TradeX made, checked, supports or endorses your version.

## If you fork and share or host it
1. Pick your own name and show it everywhere the user sees "TradeX" (page titles, logo, start-up message,
   installer, sign-in page).
2. Replace the logo and the icons in `hub/web/brand/` with your own.
3. Keep the attribution line from [NOTICE](NOTICE) and the "Source" link to your own code (the AGPL requires the
   source link for network users).
4. Internal names in the code (file names, variables, `TRADEX_*` settings) may stay. Only what users see must change.

To ask for permission, open an issue on the official repository.
